# SRE Flow Project

A retail-style app used to practice GitHub workflow, Docker, Kubernetes, AWS,
Terraform, and Splunk/Dynatrace monitoring — built as part of 45-day SRE interview prep.

## Structure
- app/ - the application
- scripts/ - automation (Bash/Python)
- docker/ - Dockerfile, docker-compose
- k8s/ - Kubernetes manifests
- terraform/ - light AWS IaC
- monitoring/ - Splunk/Dynatrace
